Understanding the CSS Box Model

Every HTML element can be considered as a box. The box model defines how the size of that box is calculated — including content, padding, border, and margin.

  • Content: The actual text or image inside the box.
  • Padding: Clears an area around the content — inside the border.
  • Border: Wraps the padding and content.
  • Margin: Clears an area outside the border — separates boxes.

By default, the total width and height of an element include only the content area. Setting box-sizing: border-box; makes the element include padding and border within its defined size, simplifying layout control.
