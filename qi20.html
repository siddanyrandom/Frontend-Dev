Head Elements Demo

This page demonstrates the essential elements commonly placed inside the <head> section:

  • <meta charset="UTF-8"> — character encoding
  • <meta name="description"> — page description
  • <meta name="author"> — author info
  • <base> — base URL for resolving relative links
  • <link rel="icon"> — favicon
  • <style> — internal CSS
  • <script> — inline JavaScript

If this file still appears blank or "not working" when you open it, try these checks:

  2. Open the browser console (F12) — you should see the console.log message.
